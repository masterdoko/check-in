# Aplicación para Registro de Contenedores - React + Vite

Este es un proyecto para el control de ingresos de contenedores en garita DT, desarrollado con React, Vite y Tailwind CSS.

## Instalación y uso

Sigue estos pasos para correr el proyecto localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/masterdoko/check-in.git
   ```
2. **Entrar a la carpeta:**
   ```bash
   cd check-in
   ```
3. **Instalar dependencias:**
   ```bash
   npm install
   ```
4. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

## Tecnologías utilizadas

**React 19**
**Vite 8** (Build tool ultra rápido)
**Tailwind CSS 4** (Estilos y diseño responsivo)
**Validaciones nativas** para formatos de contenedor.
